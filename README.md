
# 💊 Projeto: Implementação de Solução em Nuvem com AWS

## 📌 Sobre o Projeto
Este projeto tem como objetivo propor a implementação de serviços em nuvem utilizando AWS para uma empresa do setor farmacêutico que atualmente opera com infraestrutura local (on-premise).

A solução foi desenvolvida com foco na **redução de custos operacionais**, melhoria da **eficiência**, **escalabilidade** e **segurança dos dados**.

---

## 🎯 Objetivo
Identificar e aplicar 3 serviços da AWS capazes de substituir a infraestrutura local da empresa, promovendo economia e modernização tecnológica.

---

## ☁️ Serviços AWS Utilizados

### 🔹 Amazon S3
- Armazenamento de dados em nuvem  
- Substituição de servidores físicos  
- Alta durabilidade e baixo custo  

### 🔹 Amazon RDS
- Banco de dados gerenciado  
- Backup automático e alta disponibilidade  
- Redução de custos com manutenção  

### 🔹 AWS Lambda
- Computação serverless  
- Automação de processos  
- Execução sob demanda (pagamento por uso)  

---

## 🏗️ Arquitetura da Solução

A solução propõe a migração da infraestrutura local para a nuvem AWS, onde:

- Dados são armazenados no **Amazon S3**
- Informações estruturadas ficam no **Amazon RDS**
- Processos automatizados são executados via **AWS Lambda**
- Os dados podem ser utilizados em dashboards e relatórios

---

## 📊 Base de Dados

Foram utilizadas bases de dados sintéticas para simular o ambiente de uma farmácia:

- 📦 Estoque de medicamentos  
- 💰 Vendas  
- 👥 Clientes  
- 🧾 Pedidos  

Os dados foram organizados em uma planilha Excel com múltiplas abas.


---

## 💰 Comparativo de Custos

O projeto inclui uma análise comparativa entre:

- Infraestrutura local (On-Premise)
- Serviços em nuvem (AWS)

Principais reduções:
- Eliminação de servidores físicos  
- Redução de custos com energia  
- Menor necessidade de manutenção  
- Otimização de equipe técnica  

---

## ⚙️ Etapas de Implementação

1. Planejamento e análise da infraestrutura atual  
2. Criação da conta AWS e configuração de segurança  
3. Migração de dados para Amazon S3 e RDS  
4. Implementação de automações com AWS Lambda  
5. Testes e validação  
6. Monitoramento e otimização
